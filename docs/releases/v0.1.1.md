# RTMP Stream Monitor 0.1.1

This release updates the public Windows and Ubuntu probe installers and the central Docker image to the current tested code.

## Included

- Windows probe bundle with its private Python runtime, service install/uninstall support, and IPv4 per-flow TCP receiver EStats when the service account has permission to collect them.
- Ubuntu 22.04 amd64 `.deb` package with bundled Python dependencies, systemd lifecycle, enrollment, and upgrade support.
- Central Docker image `ghcr.io/sadoharu/rtmp-stream-monitor:0.1.1`, with Compose setup, persistent SQLite/log volumes, migration, backup, restore, and rollback tooling.
- Multi-probe measured-bitrate series, event timeline, and evidence-based incident explanations from the current `main` code.

## Verification limits

- Automated Windows and Ubuntu package install/upgrade/uninstall checks and Docker migration/backup/rollback fixture checks pass in GitHub Actions. These do not migrate the existing production Ubuntu server or test its rollback.
- The live `poland` RTMP feed was measured by both probe profiles from one Windows host. Independent-site localization and Windows per-flow EStats under controlled packet loss/reordering remain unverified.
- Windows TCP EStats are IPv4-only and report duplicate-ACK signals, not a packet-loss percentage. Incident causes remain unconfirmed when required observation points or current measurements are missing.
- The Windows package is not code-signed.
